Como habilitar um instrumento

Identificar provedor e operação → configurar credenciais e ambiente no cofre autorizado → verificar a operação com evidência → definir operador e laço → estabelecer teto e permissões → aprovar ativação. Sem essa sequência, o instrumento permanece apenas cadastrado.

Nenhuma chave de API deve ser digitada nesta página. Os conectores ligados diretamente ao ChatGPT não fornecem credenciais automaticamente para o Regente 1.0.
